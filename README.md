Repositorio para el proyecto de MDG. 

El objetivo del presente proyecto es aplicar la metodologia [KDG](https://www.mdpi.com/2076-3417/14/2/838)
asi como algoritmos de centralidad y de comunidad para el analisis de grafos.

En esta ocasion analizaremos las primeras 3 temporadas de la serie Game of Thrones,
los datos provienen del siguiente Repositorio: [GoT Dataset](https://github.com/mathbeveridge/gameofthrones)
